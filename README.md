## Ответы на контрольные вопросы

**1. Чем HTTP отличается от HTTPS?**
HTTPS = HTTP + шифрование (TLS) — защищает данные от перехвата и подмены.

**2. Какую роль выполняет TLS в защищённом соединении?**
Шифрование, аутентификация сервера, целостность данных — защищает от прослушивания, подделки и MitM-атак.

**3. Что такое TLS-сертификат?**  
Цифровое удостоверение — содержит публичный ключ, информацию о владельце и подпись удостоверяющего центра (CA).

**4. Что делает tls.LoadX509KeyPair? (pkg.go.dev)**  
Загружает пару "сертификат + приватный ключ" из файлов для использования в TLS-конфигурации сервера.

**5. Почему self-signed certificate подходит для локальной учебной среды, но не для публичного production-сервиса?**
Self-signed не проверяется ни одним доверенным центром сертификации — клиенты получат ошибку безопасности (нельзя подтвердить подлинность сервера в публичном интернете).

**6. Что такое SQL-инъекция?**
Внедрение злонамеренного SQL-кода через пользовательский ввод, что позволяет атаковать, читать или разрушать БД.

**7. Почему конкатенация строки SQL с пользовательским вводом опасна?**  
Пользователь может передать вместо данных часть SQL-команды, которая изменит логику запроса

**8. Что такое parameterized query?**  
Запрос с плейсхолдерами (? или $1), где данные передаются отдельно и не интерпретируются как код.

**9. Что такое prepared statement? (Go)**  
Заранее скомпилированный шаблон запроса с плейсхолдерами, который выполняется многократно с разными параметрами.

**10. Почему placeholder syntax может отличаться в разных СУБД и драйверах? (Go)**  
Разные СУБД используют разные синтаксисы: PostgreSQL — $1, $2, MySQL — ?, SQL Server — @p1. Драйверы Go следуют этим правилам.
